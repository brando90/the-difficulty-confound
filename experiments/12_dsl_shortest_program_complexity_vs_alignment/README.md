# Experiment 12: Exact shortest-program complexity versus data alignment on bit-word functions

**Doc link:** <https://github.com/brando90/the-difficulty-confound/blob/main/experiments/12_dsl_shortest_program_complexity_vs_alignment/README.md>

This experiment trains a small transformer to compute functions from 10-bit words to 10-bit words whose complexity is known exactly. The complexity is $K \in \{2, 3, 4, 5, 6\}$, the length of the shortest program that computes the function in a fixed 12-primitive domain-specific language (DSL). It is found by exhaustive breadth-first search over distinct functions. The experiment crosses that complexity with the target's share of the training mix, $\alpha \in \{0.05, 0.15, 0.4, 1.0\}$. It is the program's second exact-$K$ language, after Experiment 11's automata. It tests whether complexity raises the data bill (C1), whether alignment still dominates it in units of data (C2), and whether complexity moves the scaling-law coefficient or the exponent (C3). It also checks exact $K$ against the Coding Theorem Method (CTM), the Block Decomposition Method (BDM) and ordinary compressors.
