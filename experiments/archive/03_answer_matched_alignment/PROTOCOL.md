# Answer-matched alignment and carry demand

**Doc link:** <https://github.com/brando90/the-difficulty-confound/blob/main/experiments/03_answer_matched_alignment/PROTOCOL.md>

**TLDR:** Test whether changing only the training mixture reverses which addition stratum is harder while holding the answer distribution exactly fixed. A separate prospective prediction test asks whether an independent starting-difficulty measurement adds value beyond structure, exposure and resources.

Frozen before training on 10-16-2026. Configuration: [config.json](expt_v1/config.json). No model outcomes informed this design. A combinatorial feasibility check found 117 eligible answer values; this was not a training pilot. All results, including failures, will be published.

## Fixed construct and reference

Exact addition of two integers from 000 through 999, encoded as six one-hot decimal digits; output four decimal digits. Reuse the existing, immutable `addition.py` oracle, carry definition and network from experiment 02 byte-for-byte (record hash); do not edit reference definitions or answers. The complete population is the same 500,500 unordered pairs used in experiments 01 and 02. Only sampling and analysis change. This is a restricted population follow-up, not a new skill. No-carry means maximum carry chain 0; two-carry means chain 2 with total below 1000. Three-carry cases are excluded because their output range cannot be exactly matched to no-carry cases.

## Answer-matched sampling

Enumerate every answer below 1000 with at least 60 unordered pairs in BOTH strata. Use ALL qualifying answers (expected 117), determined from inputs and unchanged reference arithmetic only. For each answer/stratum, permute indices with the single frozen split seed, allocate eight test, four calibration and four independent probe pairs, then reserve the remaining pool for training. The same fixed test/calibration/probe questions are used for every network. Exclude these pairs and their swaps from training.

Every training set contains 40 distinct pairs per answer. Mixture q is the fraction with a two-carry chain: q in .1,.3,.5,.7,.9 gives 4,12,20,28,36 two-carry pairs and complementary no-carry counts per answer. Within seed, use fixed per-answer/stratum permutations and nested prefixes across q; reshuffle the assembled set deterministically. Training set size is 4,680 for every q. Thus the complete answer histogram and total distinct-example count are EXACTLY identical across interventions. Within every test, calibration and probe split the complete answer histogram is identical across carry strata. Save input-digit marginal diagnostics: those marginals are NOT claimed matched.

## Training and execution

Eight fresh paired seeds × five widths × five mixtures = 200 intervention trajectories. Widths 32,64,128 are predictive-law fit widths; 96,256 are held out. Fit mixtures .1,.5,.9; held-out mixtures .3,.7. Two hidden rectified-linear layers; same initialization and 500 balanced warmup updates shared within seed/width, followed by a cloned warm state for all five interventions. The independent probe is evaluated ONCE before intervention; D is mean total answer negative log likelihood in bits per stratum. AdamW, learning rate .001, weight decay .0001, batch 256; reset intervention optimizer for each cloned condition, use paired batch generators. Evaluate at 300,1000,3000 intervention updates; final checkpoint is the intervention primary. No early stopping or outcome-dependent retries. Save all final model weights, paired training indices, per-item predictions/losses, aggregates, sources, runtime hashes and all failures.

Execute on skampere2 with two CPU threads and no graphics processor. Estimated training 20–40 minutes, based on experiment 02's 25.55 minutes for the same number of trajectories; bounded at 90 minutes, under 2 GiB artifacts, no provider-key calls. Healthy numerical children survive executor replacement; no new scientific attempts after the bound.

## Primary intervention criterion

For each seed and width at 3000 updates, define E_low = accuracy(no-carry,q=.1) − accuracy(two-carry,q=.1), E_high = accuracy(two-carry,q=.9) − accuracy(no-carry,q=.9). Average widths equally WITHIN seed, then seeds equally. **Support for the prespecified rank-reversal claim requires BOTH mean gaps at least 10 percentage points, BOTH paired-seed bootstrap 95% lower limits above zero, and BOTH point gaps positive at EACH of the five widths.** The 10-point gate is a project-chosen practical margin, not a literature standard. This is a conjunction, not a selected best comparison. Bootstrap 20,000 resamples of eight complete seed blocks, holding fixed test questions; p-val=n/a. Report both gaps separately, all per-width/per-seed results, balanced-mixture structural gap and all trajectories. Do not count correlated items, widths or checkpoints as independent replicates. The uncertainty is conditional on this one sampled test set.

Descriptive factorial comparison at endpoint mixtures: A=(E_low+E_high)/2 is the alignment contrast; S=(E_low−E_high)/2 is the residual carry main effect. Report A, S and A−abs(S) with paired intervals; these are on the bounded accuracy scale for this specified 9:1 intervention. They do not partition universal causes of difficulty. Also show exact-answer accuracy and bits per answer for all cells, including q=.5.

## Secondary prospective predictive-law test

Fix five nested log-linear laws: resources = intercept + log(parameter_count) + log(intervention_updates); structure = resources + indicator(two-carry); exposure = resources + log(training_stratum_fraction); structure_exposure = resources + indicator(two-carry) + log(training_stratum_fraction); starting_difficulty = structure_exposure + log(D). Use ordinary least squares on log(mean calibration bits) separately within each seed. Exponentiate predictions, so forecasts are strictly positive; do not clip or tune. D is positive before intervention. These are power-law models for conditional answer loss, not the exact additive functional form in Varun's mathematics project. This tests the portability of a difficulty covariate, not a direct replication of his private-data result.

Fit only calibration outcomes at training widths AND training mixtures, all three checkpoints and both strata: 54 rows per seed. Freeze fit coefficients and forecasts from outcome-free features BEFORE reading any test outcomes. Score model-only, mixture-only and joint held-out targets against independent test outcomes. The main predictive comparison is starting_difficulty versus structure_exposure, on 192 joint targets (8 seeds × 2 held-out widths × 2 held-out mixtures × 3 checkpoints × 2 strata). Support requires at least 10% lower root mean squared error in bits/answer, a positive 95% paired-seed-bootstrap lower bound, and a positive improvement at both held-out widths. All five laws and all three splits are reported, including mean absolute error, signed bias (forecast minus observation), both means and finite/positive forecast counts. Also compare structure_exposure versus structure (incremental exposure value) and versus exposure (incremental structural value), labelled secondary contrasts. No fitted test outcomes or held-out calibration outcomes may influence coefficients or model selection. Report prediction errors on observed scale, not training log scale.

## Interpretation limits and checks

This design controls exact answer frequencies, distinct training set size, compute, architecture within width, notation, task and evaluation items. It does not match all operand digit marginals or prove identical internal strategies. Carry-chain length is a concrete structural demand under standard column addition, not Kolmogorov complexity. A fixed reference program and unchanged item have unchanged description complexity relative to a fixed universal machine; uncomputable shortest-program length is not estimated here. Data alignment can change learned loss without changing the function's computational complexity. A crossover supports training-dependent difficulty rankings on this population; it cannot show complexity never matters or that data dominates across language models.

Deterministic checks: unchanged oracle hash; exhaustive original arithmetic checks; exact answer histogram equality; disjoint split IDs including operand swaps; all 200 cells and all saved per-item counts reconciled; aggregate recomputation; paired-seed uncertainty independently recomputed; replay every final weight on both evaluation splits and compare saved predictions/losses; forecast feature schema excludes outcomes; all fit rows exclude held-out widths/mixtures; complete positive finite forecast checks. Preserve all declared cells including failures.
